Backtest range
Discovery / validation split
Tune params watching the DISCOVERY window, then check the same params, untouched, on the VALIDATION window. A real edge holds up out-of-sample; an overfit one falls apart on contact with data it never saw -- the single best defense against curve-fitting.
Robustness testing
Takes the last N real days and builds many SYNTHETIC sequences by resampling those real days with replacement -- same real intraday bars throughout, just a different possible ORDER/mix of days. Answers: "how much does the exact sequence I happened to get matter, if conditions had shuffled a different way?"
Runs the same strategy across many random REAL windows pulled from anywhere in the loaded history. Answers: "how much does my result depend on which historical period I happened to test on?"
How this works: pick a strategy, data downloads itself (cached after the first time), results update live as you change settings. It mirrors TradingView's fill engine but isn't TradingView — treat results as structure-testing, not penny-exact. Tip: set slippage to 1–2 ticks before trusting anything.
